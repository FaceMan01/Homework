sequenceDiagram
  actor User
  participant Frontend as Frontend
  participant Backend as Backend
  participant YOLO as YOLO

  User ->> Frontend: Загружает модель / выбирает предустановленную
  Frontend ->> Backend: Передаёт путь к модели
  Backend ->> Backend: Проверка модели
  Backend ->> YOLO: Загрузка модели
  alt Обработка изображений
    User ->> Frontend: Загружает изображения
    Frontend ->> Backend: Передаёт изображения
    loop 
        Backend ->> YOLO: Передаёт изображене
        YOLO -->> Backend: Аннотированное изображение
    end
    Backend -->> Frontend: Передаёт результаты
    Frontend -->> User: Отображает галерею результатов
  
  else Обработка видео
    User ->> Frontend: Загружает видео
    Frontend ->> Backend: Передаёт видео
    Backend ->> Backend: Разбиение видео на кадры
    loop 
        Backend ->> YOLO: Передаёт кадр
        YOLO -->> Backend: Аннотированный кадр
    end
    Backend ->> Backend: Сбор кадров в видео
    Backend -->> Frontend: Передаёт результат
    Frontend -->> User: Показывает видео
  end
  Backend -->> Frontend: Статусы и ошибки
  Frontend -->> User: Отображение прогресса и сообщений
